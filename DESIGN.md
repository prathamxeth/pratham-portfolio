# Visual System & Design Language — Prathmesh Upadhyay Portfolio

## Aesthetic World: Swiss Editorial Precision x Modern Technical Craft
- **Voice**: Measured, authoritative, architectural, direct.
- **Hierarchy**: Editorial typography first, generous whitespace, sharp hairline dividers, restrained palette.

## Color Palette
- **Light Theme**:
  - Background: `#ffffff`
  - Foreground (Primary): `#09090b` (WCAG AAA)
  - Secondary/Muted: `#52525b` (WCAG AA 5.8:1)
  - Hairline Borders: `#e4e4e7`
  - Accent / Dark Actions: `#18181b` with `#ffffff` text
- **Dark Theme**:
  - Background: `#09090b`
  - Foreground (Primary): `#fafafa`
  - Secondary/Muted: `#a1a1aa`
  - Hairline Borders: `#27272a`
  - Accent / Light Actions: `#fafafa` with `#09090b` text

## Typography
- **Primary Body/Display**: System Sans Stack (`-apple-system, BlinkMacSystemFont, "SF Pro Text", "Segoe UI", sans-serif`) with `-0.015em` tracking.
- **Code/Data**: `ui-monospace, SFMono-Regular, Menlo, Monaco, Consolas, monospace`.
- **Measure**: Body line lengths strictly constrained to `65ch` to maintain reading comfort.

## Rules & Bans
- No eyebrow/kicker labels above main headings. Headings speak for themselves.
- No gradient text or zero-offset ambient blur halos.
- No generic purple/indigo AI clichés.
- Single elevation declaration per surface.
- Easing: Natural exponential deceleration (`cubic-bezier(0.16, 1, 0.3, 1)`).
